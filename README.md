# 🌸 SmileSteps

A child-friendly MERN web application for children with developmental disabilities.

## 🚀 Live Demo
👉 **[Click here to view live app](https://smile-steps.vercel.app)**

## 🔗 Live Links
- **Frontend:** https://smile-steps.vercel.app
- **Backend API:** https://smilesteps.onrender.com

## 🛠️ Tech Stack
- React.js + Vite (Frontend)
- Node.js + Express (Backend)
- MongoDB Atlas (Database)
- Vercel (Frontend Hosting)
- Render (Backend Hosting)
